# Edit and recolor SVGs in Google Slides™

Once converted with SVG to Slides, every path in your SVG is a separate native Slides shape. Select one element and change its fill with the standard picker, edit its points, or animate it on its own.

_Free forever. Every feature, no daily cap, no account, no Pro tier._

- Install the Chrome extension: https://chromewebstore.google.com/detail/svg-to-slides/bdhhnakellmdnbgbdokiojipaebdeioi
- Online converter: https://svgslid.es/convert

## What you can do
- **Select individual elements.** Every path is its own selectable shape, not one flattened image.
- **Recolour with the fill picker.** Change any shape's colour directly in Slides. No re-exporting.
- **Edit points.** Right-click → Edit points, like any shape you drew yourself.
- **Animate each shape.** Build transitions element by element instead of animating one image.

## Questions

### Can I change the color of an SVG in Google Slides?
Yes, once it's converted. SVG to Slides turns each path into a native shape, so you can recolour any element with the standard fill picker.

### Can I edit the points of an SVG shape?
Yes. Right-click a converted shape and choose Edit points, like any native shape.

### What about gradients?
Solid fills and strokes convert cleanly. Gradients come through in the online converter; in the Chrome extension and add-on they currently collapse to a single solid colour.
