# How to edit points in Google Slides™

Install SVG to Slides, double-click the shape and click Edit Shape. Drag a point to move it, click a point to show its curve handles, then click Done. The shape updates in place and keeps its place in the stack.

- See every editing tool: https://svgslid.es/vector-editor

## How to do it
1. **Open Edit Shape.** Double-click the shape, then click Edit Shape. You can also select it and click Edit Shape on the extension’s toolbar.
2. **Move points and curves.** Drag a point to move it. Click a point to see its curve handles, and drag a handle to change the curve.
3. **Add or remove points.** Press P, then click the outline to add a point, or click a point to remove it.
4. **Click Done.** Or press Enter. The edited shape takes the original’s place, and the whole session is one undo step.

## Point and curve keys
- Smooth or corner point: double-click the point.
- Move one handle only: hold Option (Alt on Windows) while dragging it.
- Keep to 45° steps: hold Shift while dragging.
- Select several points: Shift-click each one, or drag a box around them.
- Nudge: arrow keys. Hold Shift for ten times the step.
- Undo and redo, point by point: Command+Z and Shift+Command+Z (Ctrl on Windows).
Every key is in the Edit Shape reference.

## Slides’ own shapes, lines and WordArt
- Edit Shape also opens on shapes from Slides’ shape menu, arrows, callouts, lines, text boxes and WordArt. It converts the object into custom shapes first.
- Beside the Edit Shape button, a grey note says what the conversion costs, for example “text becomes outlines”. Cancel puts the original back.
- A preset shape loses its adjustment handles. Text inside a shape stays editable. WordArt becomes letter outlines you can reshape but not retype.
What each object becomes.

## More than points
- The box. Drag a corner to scale, an edge to stretch, Command and an edge to skew, Command and a corner to rotate. The points stay editable.
- Exact values. The pill under the shape holds width, height and rotate-by. Type a value and press Enter.
- Round corners. Drag the small circle inside a corner, or type a radius. Rounding corners.

## Questions

### Can you edit points in Google Slides without an extension?
Only on polylines: shapes with straight segments only. Curved shapes and shapes with holes need Edit Shape. Why.

### Can I edit the points of an SVG?
Yes. Insert the SVG with SVG to Slides, so every path arrives as its own shape, then double-click a shape and click Edit Shape.

### Are animations kept after I edit a shape?
No. Done puts a new object in place of the original, so animations and links attached to it do not carry over.

### What can't be edited as a shape?
Images, video and charts.
