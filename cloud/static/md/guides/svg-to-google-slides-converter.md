# SVG to Google Slides™ converter

SVG to Slides converts SVG files into native, editable Google Slides shapes. Use the Chrome extension to drop files straight onto a slide, or the web converter to turn a batch of SVGs into a Slides-ready file in Google Drive. Every surface is free.

_Free forever. Every feature, no daily cap, no account, no Pro tier._

- Install the Chrome extension: https://chromewebstore.google.com/detail/svg-to-slides/bdhhnakellmdnbgbdokiojipaebdeioi
- Online converter: https://svgslid.es/convert

## Pick your route
- **Chrome extension** — Drag an SVG straight onto an open Slides tab and drop it in place. No dialog, no upload step. Converts in your browser. (https://chromewebstore.google.com/detail/svg-to-slides/bdhhnakellmdnbgbdokiojipaebdeioi)
- **Web Uploader** — Upload one or more SVGs and get back a Google Drive link to a Slides-ready file, one slide per SVG. Best for bulk conversion or building an icon library. (https://svgslid.es/convert)
- **Google Slides add-on** — Insert SVGs into a presentation you're already editing, from a dialog inside Slides itself. (https://svgslid.es/addon)

## Which converter to use

| You want to | Use | Why |

| Convert a whole icon set at once | Web uploader | One slide per SVG, in one Google Drive file. |

## What each converter keeps
- Every surface converts paths, basic shapes, arcs, transforms and even-odd cut-outs into native shapes.
- Gradients and text come through on the web uploader only.
- Clip paths, masks, patterns, filters and transparency don't come through on any surface. See the tested results for 20 SVG features.

## Questions

### Is there an online SVG to Google Slides converter?
Yes. Upload SVGs at svgslid.es/convert. No install needed. You get a Google Drive link to a file with one slide per SVG.

### Do I need an account?
No account is required for the extension. The web converter takes an optional Google account email if you want the file shared directly to you.

### How long does the web converter keep my file?
The link stays active for 7 days. To keep a file, open it in Drive and choose File → Make a copy. The copy is fully yours, with no expiry.
