# How to insert an SVG into Google Slides™

Google Slides doesn't support SVG files, so you can't upload one as an editable graphic. To insert an SVG into Google Slides, install the free SVG to Slides Chrome extension, open your presentation, and drag the .svg file onto a slide. Each path becomes its own native Slides shape.

_Free forever. Every feature, no daily cap, no account, no Pro tier._

- Install the Chrome extension: https://chromewebstore.google.com/detail/svg-to-slides/bdhhnakellmdnbgbdokiojipaebdeioi
- Online converter: https://svgslid.es/convert

## How to do it
1. **Install the free Chrome extension.** Add SVG to Slides from the Chrome Web Store. No account required.
2. **Open your presentation in Google Slides.** Any existing or new deck.
3. **Drag the SVG file onto a slide.** Click where it goes. It lands there and its paths become editable shapes. Up to 25 SVG files per drop.

## Reshape it after you insert it
- Double-click any shape and click Edit as SVG. A vector editor opens on the slide at the shape’s exact size, so you can drag its points and curve handles, add or remove points, and undo as you go. Click Done and the shape updates in place.
- It works on Slides’ own shapes, lines and WordArt too. What’s new in 1.2.

## Import an SVG without installing anything
- Web uploader. Upload one or more SVG files at svgslid.es/convert and get a Google Drive link to a Slides-ready file, one slide per SVG. Good for bulk conversion.
- Google Slides add-on. Insert SVGs from a dialog inside Slides, without leaving the tab. Get the add-on.

## Insert SVG icons into Google Slides
- Download icons as SVG files from any icon library and drag them onto your slide, up to 25 per drop.
- Each icon arrives as native shapes with no background box, so you can recolour it with the fill picker to match your theme.
- For a whole icon set, upload it at svgslid.es/convert and get one slide per icon, ready to copy from.

## The manual workaround: EMF and Google Drawings
1. Convert the SVG to an EMF or WMF file with a desktop or online converter.
2. Upload the EMF or WMF file to Google Drive.
3. Open it with Google Drawings.
4. Copy the shapes and paste them into your Google Slides presentation.
It works, but it's four steps for every file.

## The Microsoft PowerPoint route
1. In PowerPoint, choose Insert → Pictures and pick the SVG file.
2. Right-click the graphic and choose Convert to Shape.
3. Save the presentation as .pptx and upload it to Google Drive.
4. Open it with Google Slides and copy the shapes into your deck.
It needs a PowerPoint licence and a round trip through Drive for every graphic.

## Questions

### How do I import an SVG into Google Slides?
Install the free SVG to Slides Chrome extension and drag the SVG file onto a slide, or upload it at svgslid.es/convert. Both turn every path into a native, editable Slides shape.

### Can I upload an SVG to Google Slides directly?
Not as an editable graphic. Without a converter, your options are to flatten it into a PNG or take the long way through EMF conversion, Google Drawings, and copy-paste. SVG to Slides converts the file into native Slides shapes instead.

### Can I insert SVG icons into Google Slides?
Yes. Drag up to 25 SVG icons onto a slide at once. Each one becomes editable shapes you can recolour and resize without losing quality.

### How many SVGs can I insert at once?
Up to 25 per drop with the Chrome extension. For larger batches, use the bulk converter at svgslid.es/convert.

### Does it cost anything?
Free forever. Every feature, no daily cap, no account, no Pro tier.

### Is my file uploaded anywhere?
The Chrome extension converts on your device using an embedded WebAssembly engine, so your file usually never leaves the browser. The web converter and add-on send the file to our backend for conversion.
