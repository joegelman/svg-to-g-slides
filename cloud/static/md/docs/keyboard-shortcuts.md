# Keyboard shortcuts

Applies to: SVG to Slides Chrome extension, version 1.3.0. Editor keys also apply to version 1.2.0 unless they name a 1.3.0 tool..

Availability: Version 1.3.0 is not in the Chrome Web Store yet. The store installs version 1.2.0. See [what each version has](https://svgslid.es/docs/release-notes.md#matrix).

All shortcuts, with the Mac and Windows keys side by side. The extension's own shortcuts work while objects are selected and you are not typing in a text box. Five of them work at any time.

> **Note:** The extension's shortcuts are off while the cursor is in a text box, so that typing Option+Shift characters still works. Click the slide or an object first.

## Tools and panels

These work whether or not anything is selected.

| Command | Mac | Windows |
|---|---|---|
| Show or hide the toolbar | Option+\ | Alt+\ |
| Command palette | Command+\ | Ctrl+\ |
| Show or hide Layers | Option+1 | Alt+1 |
| Pen | Option+Shift+P | Alt+Shift+P |
| Theme builder, and back | Option+Shift+M | Alt+Shift+M |
| Edit Shape | Double-click, then Edit Shape | Double-click, then Edit Shape |
| Select inside a group | Command-click | Ctrl-click |
| Undo one of the extension's changes | Command+Z | Ctrl+Z |
| Redo it | Shift+Command+Z | Ctrl+Shift+Z |

## Arrange, rotate and resize

These are Google Slides' own shortcuts. The toolbar and the command palette list them, and Slides carries them out.

| Command | Mac | Windows |
|---|---|---|
| Bring to front | Shift+Command+Up Arrow | Ctrl+Shift+Up Arrow |
| Bring forward | Command+Up Arrow | Ctrl+Up Arrow |
| Send backward | Command+Down Arrow | Ctrl+Down Arrow |
| Send to back | Shift+Command+Down Arrow | Ctrl+Shift+Down Arrow |
| Rotate 15° left or right | Option+Left Arrow | Alt+Left Arrow |
| Rotate 1° left or right | Option+Shift+Left Arrow | Alt+Shift+Left Arrow |
| Make larger | Command+Control+K | Ctrl+Alt+K |
| Make smaller | Command+Control+J | Ctrl+Alt+J |

## In Edit Shape and the pen

On Windows use Ctrl for Command, Alt for Option and Backspace for Delete.

| Action | Keys |
|---|---|
| Select tool | V |
| Pen tool | P |
| Move a point or handle in 45° steps | Hold Shift while dragging |
| Move one curve handle on its own | Hold Option while dragging it |
| Switch a point between smooth and corner | Double-click the point |
| Select all points | Command+A |
| Delete selected points. In the pen, remove the last point. | Delete |
| Nudge | Arrow keys. Shift for ten times the step. |
| Undo, redo | Command+Z, Shift+Command+Z |
| Zoom in, zoom out, 100% | Command+Plus, Command+Minus, Command+0. Or pinch. |
| Pan | Hold Spacebar and drag, or scroll |
| Show or hide the grid | Command+' |
| Ignore snapping for one move | Hold Command |
| Change a number by dragging | Hold Option and drag across the field. Shift for steps of ten. |
| Round corners in 10 pixel steps | Hold Shift while dragging a corner circle |
| Scale in proportion, or from the centre | Shift, Option while dragging the box |
| Skew | Command and drag an edge of the box |
| Rotate | Command and drag a corner of the box |
| Pen: close the shape | Click the first point |
| Pen: leave the path open | Enter or Esc |
| Done | Enter, or Esc with nothing selected |

## Where the keys come from

Align and distribute use the keys Figma uses. Rotate, resize, arrange, group and ungroup are Google Slides' own shortcuts. The rest are the extension's.
