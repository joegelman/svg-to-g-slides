# Installing and updating the extension

Applies to: SVG to Slides Chrome extension, versions 1.0.0 through 1.3.0.

The extension installs from the Chrome Web Store and needs no account. It runs only on Google Slides editor pages. Chrome updates it automatically.

## Requirements

| Item | Requirement |
|---|---|
| Browser | Google Chrome on a desktop computer. |
| Page | A Google Slides presentation open for editing. The extension does not run on other pages. |
| Account | None. |
| Chrome permissions | Version 1.3.0: storage. Earlier versions: see [Permissions and data](https://svgslid.es/docs/permissions-privacy.md#by-version). |

**To install the extension**

1. Open [svgslid.es/chrome](https://svgslid.es/chrome). It leads to the SVG to Slides page in the Chrome Web Store.
2. Click **Add to Chrome**.
3. Open a Google Slides presentation. If one was already open, reload its tab.

In version 1.3.0 a round button appears at the left edge of the slide canvas. That button is the toolbar, closed. See [The toolbar](https://svgslid.es/docs/toolbar.md).

## Checking your version

**To see which version is installed**

1. In Chrome's address bar, type `chrome://extensions` and press Enter.
2. Find **SVG to Slides**. The version number is shown beside the name.

Each topic in this library states the versions it applies to. If a tool described here is missing, compare your version with the topic's box.

## How updates arrive

Chrome updates extensions on its own, usually within a few hours of a new version being published in the Chrome Web Store. You do not need to do anything.

The first time you open Slides after an update, a short note in the corner of the page names what changed and links to the release post. It appears once. New installations do not see it.

> **Note:** An update can change the permissions the extension holds. Version 1.3.0 removes one. See [Version 1.3.0](https://svgslid.es/docs/release-notes/1-3-0.md#packaging).
