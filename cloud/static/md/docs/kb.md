## Kinds of article

| Prefix | Meaning |
|---|---|
| PRB | A problem and its cause. The behaviour may be by design. |
| FIX | A problem that a later version corrects. |
| INFO | Background on how something behaves. |
| HOWTO | A procedure. |

## If your problem is not listed

Check [Limits and known issues](https://svgslid.es/docs/limits.md) and [SVG feature support](https://svgslid.es/docs/svg-compatibility.md). If a file does not convert, send the .svg file itself to the address on the [Support](https://svgslid.es/support) page. Most conversion problems are specific to how one file was exported.
