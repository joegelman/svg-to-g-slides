# Versions 1.0.0 and 1.0.1: technical changelog

Applies to: SVG to Slides Chrome extension, versions 1.0.0 and 1.0.1.

Version 1.0.0 is the first release: drag SVG files onto a Google Slides tab and they land as native, editable shapes, converted inside the browser. Version 1.0.1 removed an unused permission.

## Version 1.0.1

July 2026.

| Mark | Change |
|---|---|
| REM | The activeTab permission. The extension did not use it, and Chrome Web Store review flagged it. |

## Version 1.0.0

July 2026. First release.

| Mark | Change |
|---|---|
| NEW | Drag one or more .svg files onto an open Google Slides tab. A preview follows the pointer. |
| NEW | Place the graphic, then press Command+V to confirm. The shapes land as native Slides shapes, one per path, grouped per file. |
| NEW | Up to 25 files per drop, laid out in a grid on the current slide. |
| NEW | Conversion runs inside the browser. The converter was the project's Python converter, compiled to WebAssembly. A converter on the svgslid.es server was the fallback. |
| NEW | No Google sign-in and no Google permissions. |

## How 1.0 differs from later versions

| In 1.0 | Since |
|---|---|
| Every insert ended with Command+V. | 1.2.0: the click places the shapes. |
| Position was estimated from the window size. See [FIX: Inserted shapes landed away from the pointer in versions 1.0.0 and 1.0.1](https://svgslid.es/docs/kb/shapes-land-away-from-pointer.md). | 1.2.0: measured from the slide. |
| No editing tools. | 1.2.0: [Edit Shape: points and curves](https://svgslid.es/docs/edit-shape.md). 1.3.0: [The toolbar](https://svgslid.es/docs/toolbar.md). |
| The extension carried a Python runtime. | 1.3.0: a JavaScript converter. See [How conversion works](https://svgslid.es/docs/how-conversion-works.md#javascript). |
