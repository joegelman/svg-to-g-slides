# Version 1.2.0: technical changelog

Applies to: SVG to Slides Chrome extension, version 1.2.0.

Version 1.2.0 adds Edit Shape, a vector editor that opens on the slide, and corner rounding. It works on Slides' own shapes as well as inserted ones. Inserting no longer needs a paste: the click places the shapes.

| Item | Detail |
|---|---|
| Version | 1.2.0 |
| Date | November 2026 |
| Download size | 5.8 MB |
| Installed size | 14 MB |
| Chrome permissions | storage, and one host permission for the converter fallback |

## Editor

| Mark | Change | Topic |
|---|---|---|
| NEW | Edit Shape. Double-click a shape and click **Edit Shape**. An editor opens on the slide at the shape's exact size and position: drag points and curve handles, add and remove points, select several, undo, redo, zoom and pan. **Done** updates the shape in place. | [Edit Shape: points and curves](https://svgslid.es/docs/edit-shape.md) |
| NEW | Round corners. Drag a circle inside a corner or type a radius in pixels. A whole shape or several shapes round together. | [Rounding corners](https://svgslid.es/docs/round-corners.md) |
| NEW | Edit Shape opens on Slides' own shapes, lines, text boxes and WordArt by converting them to custom shapes first. The conversion reads the outlines Slides itself draws. **Cancel** restores the original. | [Editing Slides' own shapes](https://svgslid.es/docs/convert-slides-shapes.md) |
| NEW | Shapes stacked above the one being edited stay visible, and **Done** returns each edited shape to its place in the stack. | [Edit Shape: points and curves](https://svgslid.es/docs/edit-shape.md#done) |

## Inserting

| Mark | Change | Topic |
|---|---|---|
| CHG | Click to insert. Drop an SVG and click where it goes. The shapes land with nothing to paste. If Slides does not accept them, the extension asks for Command+V. | [Inserting SVG files](https://svgslid.es/docs/insert-svg.md) |
| CHG | Placement is measured from the slide. Earlier versions estimated it from the window size. | [FIX: Inserted shapes landed away from the pointer in versions 1.0.0 and 1.0.1](https://svgslid.es/docs/kb/shapes-land-away-from-pointer.md) |

## Converter

| Mark | Change | Topic |
|---|---|---|
| CHG | Shapes with one outline, straight segments only and no more than 150 points land as Slides polylines, so Slides' own Edit points works on them. | [Edit points and polylines](https://svgslid.es/docs/edit-points-and-polylines.md) |
| FIX | For those shapes, a closing segment that repeated the start point is dropped. It left two points in one place, and dragging one tore the corner. |  |

## Fixes

| Mark | Change |
|---|---|
| FIX | Placement and the editor measure the slide you have open. Before, visiting another slide first could throw both off. |
| FIX | The editor measures the visible canvas, so editing while Slides is zoomed in works. |
| FIX | Shapes picked from inside a group are placed correctly when edited. |

## Permissions and updates

| Mark | Change |

Version 1.3.0 changes parts of what is described here: the editor's toolbar, the permissions and the converter. See [Version 1.3.0](https://svgslid.es/docs/release-notes/1-3-0.md).
