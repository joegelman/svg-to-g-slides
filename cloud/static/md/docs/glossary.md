# Glossary

Applies to: All SVG to Slides documentation.

Terms used in this library, in alphabetical order.

### Add-on {#add-on} The SVG to Slides Workspace Add-on. It runs inside Google Slides from the Extensions menu. See [Workspace Add-on](https://svgslid.es/docs/add-on.md).

### Box {#box} The frame with handles around the selection in Edit Shape. Dragging it scales, stretches, skews or rotates. See [Edit Shape: points and curves](https://svgslid.es/docs/edit-shape.md#smart-box).

### Combine {#combine} To make one shape from several with Union, Subtract, Intersect or Exclude. See [Combining shapes](https://svgslid.es/docs/combine-shapes.md).

### Command palette {#command-palette} A searchable list of every command, opened with Command+\. See [The command palette](https://svgslid.es/docs/command-palette.md).

### Corner point {#corner-point} A point where the outline turns sharply. Drawn as a square in Edit Shape. Compare *smooth point*.

### Custom shape {#custom-shape} A Slides shape defined by its own outline, as opposed to a preset from the shape menu. Every shape SVG to Slides inserts is a custom shape or a polyline.

### Flatten {#flatten} What Slides does to an SVG placed on a slide without SVG to Slides: it turns the drawing into a picture made of pixels.

### Handle {#handle} One of the two control points beside a smooth point. Dragging a handle changes the curve on that side of the point.

### Layout {#layout} A slide design in the theme that slides are based on. Objects on a layout appear on every slide that uses it. See [Theme objects](https://svgslid.es/docs/theme-objects.md).

### Mask {#mask} A shape used to cut a picture so that the picture shows only inside the shape. See [Masking an image](https://svgslid.es/docs/mask-image.md).

### Master {#master} The top level of a Slides theme. Objects on the master appear on every layout and slide. See [Theme objects](https://svgslid.es/docs/theme-objects.md).

### Native shape {#native-shape} A shape that Slides treats as its own: it can be selected, filled, resized, grouped, used in themes and copied to Google Drawings.

### Outline {#outline} As a verb: to turn a stroke or text into filled shapes. As a noun: the path that defines a shape's edge. See [Outlining strokes and text](https://svgslid.es/docs/outline-stroke-text.md).

### Path {#path} In an SVG file, a sequence of lines and curves. Each path becomes one Slides shape.

### Pill {#pill} The small dark panel under the selection in Edit Shape that holds width, height, rotation and corner radius.

### Polyline {#polyline} A Slides shape made of straight segments, on which Slides' own Edit points command works. See [Edit points and polylines](https://svgslid.es/docs/edit-points-and-polylines.md).

### Scrub {#scrub} To change a number by holding Option and dragging across its field.

### Smooth point {#smooth-point} A point where the outline curves through without a corner. Drawn as a circle in Edit Shape. It has two handles.

### Snapping {#snapping} Pulling a point onto a nearby point, pixel or grid line as you place or drag it. See [Snapping](https://svgslid.es/docs/snapping.md).

### Still copy {#still-copy} A picture of the slide that the extension shows while a change takes several steps, so that only the result is seen. See [Multi-step changes and undo](https://svgslid.es/docs/undo-and-still-copy.md).

### Stroke position {#stroke-position} Whether a stroke sits inside, on, or outside a shape's outline. See [Outlining strokes and text](https://svgslid.es/docs/outline-stroke-text.md#position).

### Theme object {#theme-object} An object drawn on a slide that belongs to the slide's layout or master. It cannot be changed on the slide. See [Theme objects](https://svgslid.es/docs/theme-objects.md).

### Toolbar {#toolbar} The strip of buttons the extension adds at the left edge of the slide canvas. See [The toolbar](https://svgslid.es/docs/toolbar.md).

### Web Uploader {#web-uploader} The page at svgslid.es/convert that converts SVG files to a Drive file. See [Web Uploader](https://svgslid.es/docs/web-uploader.md).
