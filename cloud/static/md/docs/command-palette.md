# The command palette

Applies to: SVG to Slides Chrome extension, version 1.3.0 and later.

Press Command+\ to open a searchable list of every command with its shortcut. Type a few letters, move with the arrow keys and press Enter to run the command.

**To run a command by name**

1. Press Command+\, or click **Commands** on the toolbar.
2. Type part of the command's name. The list narrows as you type.
3. Press Up Arrow or Down Arrow to move, and Enter to run the command.

Press Esc, or Command+\ again, to close the palette without running anything.

![The command palette open over a slide: a search field reading Type a command and a list grouped under Shape tools, Outline, Arrange, and Align and distribute, each command with its shortcut at the right](https://svgslid.es/static/docs/img/command-palette.jpg)
Figure 1. The command palette. Shortcuts are listed at the right of each command.

## What the palette lists

Commands are grouped: Shape tools, Outline, Arrange, Align and distribute, Combine, Group, Fill and stroke, Transform and stroke. The full list with descriptions is in [Command reference](https://svgslid.es/docs/commands.md).

Commands that need a selection are dimmed while nothing is selected. The Pen, the Layers panel, the toolbar and the theme builder can be opened at any time.
