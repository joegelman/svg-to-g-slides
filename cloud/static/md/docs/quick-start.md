# Quick start: your first SVG

Applies to: SVG to Slides Chrome extension, versions 1.2.0 and 1.3.0.

Availability: Version 1.3.0 is not in the Chrome Web Store yet. The store installs version 1.2.0. See [what each version has](https://svgslid.es/docs/release-notes.md#matrix).

Drag an .svg file onto a slide, click where it goes, and it lands as native shapes. This topic walks through the first insert and the three things most people do next.

**To put an SVG on a slide**

1. Open your presentation in Google Chrome with the extension installed.
2. Drag an .svg file from a folder on your computer onto the slide. A faint preview follows the pointer with the label **Click to Place**.
3. Click where the graphic should go. It lands there as shapes, selected.

![A Google Slides slide with a faint palm icon under the pointer and a pill reading Click to Place](https://svgslid.es/static/docs/img/insert-click-to-place.jpg)
Figure 1. The file has been dropped. The preview follows the pointer until you click.

## What to do next

| To do this | Do this |
|---|---|
| Change a colour | Select a shape and use Slides' fill picker. Each path of the SVG is its own shape, so parts recolour separately. |
| Resize | Drag a selection handle. The shapes are vectors, so edges stay sharp at any size. |
| Work on one part | Shapes from one file arrive grouped. Double-click to reach a shape inside the group. In version 1.3.0 you can also hold Command and click it. See [The Layers panel](https://svgslid.es/docs/layers.md#direct-select). |
| Change the outline | Double-click a shape and click **Edit Shape**. See [Edit Shape: points and curves](https://svgslid.es/docs/edit-shape.md). |
| Open the tools | In version 1.3.0, click the round button at the left of the slide, or press Option+\. See [The toolbar](https://svgslid.es/docs/toolbar.md). |

> **Tip:** To bring in many files, select up to 25 and drag them together. See [Inserting SVG files](https://svgslid.es/docs/insert-svg.md#several).
