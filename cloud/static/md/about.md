# About SVG to Slides

SVG to Slides turns SVG files into native, editable shapes inside Google Slides. Every path becomes its own shape: select it, recolour it with the standard fill picker, resize it without losing quality.

- Three ways in: Chrome extension (https://chromewebstore.google.com/detail/svg-to-slides/bdhhnakellmdnbgbdokiojipaebdeioi), web uploader (https://svgslid.es/convert), Google Slides add-on (https://svgslid.es/addon).
- The extension asks for no access to your Google account.
- Free forever. Every feature, no daily cap, no account, no Pro tier.

## Why it exists
Slides has no way to import an SVG; pasted SVGs flatten into images. Where there should be crisp icons and logos, there are crunchy PNGs.

## How it works
SVG to Slides writes Google Slides' own clipboard shape format from your SVG's paths and hands it to Slides, which treats the result as native shapes. The extension converts inside your browser. Since 1.2 it also edits shapes: double-click any shape to move its points and curves (https://svgslid.es/whats-new).
