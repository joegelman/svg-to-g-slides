# SVG to Slides guides

Featured: [Does Google Slides&trade; support SVG?](https://svgslid.es/guides/does-google-slides-support-svg.md)

## Start here
- [SVG vs PNG in Google Slides&trade;](https://svgslid.es/guides/svg-vs-png-google-slides.md): When Google Slides flattens an SVG it becomes a single image that blurs when resized and can't be recoloured or edited. SVG to Slides converts every path into Slides' own native shape format instead, so the result behaves like a shape you drew yourself.
- [Insert an SVG into Google Slides&trade;](https://svgslid.es/guides/insert-svg-into-google-slides.md): Google Slides doesn't accept SVG files as editable graphics. To insert one, install the free SVG to Slides Chrome extension, open your presentation, and drag the .svg file onto a slide. Each path becomes its own native Slides shape.
- [Does Google Slides&trade; support SVG?](https://svgslid.es/guides/does-google-slides-support-svg.md): No. Google Slides doesn't keep SVG files as editable vectors. Your options are to flatten the SVG into a PNG, or convert it through EMF and Google Drawings. SVG to Slides converts the file into Slides' native shape format, so it stays editable.

## Design workflows
- [SVG to Google Slides&trade; converter](https://svgslid.es/guides/svg-to-google-slides-converter.md): SVG to Slides converts SVG files into native, editable Google Slides shapes. Use the Chrome extension to drop files straight onto a slide, or the web converter to turn a batch of SVGs into a Slides-ready file in Google Drive. Every surface is free.
- [Edit and recolor SVGs in Google Slides&trade;](https://svgslid.es/guides/recolor-svg-in-google-slides.md): Once converted with SVG to Slides, every path in your SVG is a separate native Slides shape. Select one element and change its fill with the standard picker, edit its points, or animate it on its own.
- [SVG logos and icons in Google Slides&trade; themes](https://svgslid.es/guides/svg-logos-icons-google-slides.md): Convert your logo or icon set with SVG to Slides, add it to your theme layouts, and reuse it on every slide. The shapes resize without losing quality and also work in Google Drawings.
