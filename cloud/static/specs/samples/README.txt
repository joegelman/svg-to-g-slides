SVG to Slides test files

20 small SVGs, one feature each, used to test what SVG to Slides converts.
Results: https://svgslid.es/specs

Several files mimic common export styles (Adobe Illustrator CSS classes,
Figma clip-path frames, Lucide/Feather line icons). They were written for
these tests, not exported from those apps.

Free to use for any purpose.
