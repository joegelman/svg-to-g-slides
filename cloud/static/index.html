SVG files → editable vector shapes in Google Slides

How it works

  1. Upload one or more .svg files using the drop zone or file browser.
  2. Every <path> element in your SVG is converted to a discrete, individually selectable vector shape in Google Slides — not a flattened image.
  3. Each SVG becomes one slide in the output file.
  4. The resulting PPTX is uploaded to Google Drive and a shareable link is returned.
  5. Open the link in Drive → File → Save to Drive → File → Make a copy to get a fully editable native Slides file.
  6. If you enter a Google account email, the file is shared directly to that account so it appears in your Drive.

Note: Arc commands (A/a) in SVG paths are approximated as straight lines. Re-export with more path segments if curves appear angular.
